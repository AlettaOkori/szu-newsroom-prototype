# 智媒编辑部演示原型 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建可离线演示的「智媒编辑部」AI 新闻生产全流程交互原型（六模块 + 全局组件，纯前端 Mock）。

**Architecture:** 单页应用，单一全局状态对象驱动七个视图（display 切换，无路由库）；所有 AI 输出由统一打字机引擎渲染预置文案；Mock 数据独立于逻辑，按模块拆分数据文件。

**Tech Stack:** HTML5 + CSS3 + 原生 ES6 JS（`<script>` 直接引入，无构建工具、无任何第三方依赖）。测试为浏览器手动验收（对照各模块 PRD 测试用例），无自动化测试框架。

## Global Constraints

- 零依赖：不引入任何库/字体/图标 CDN，双击 `demo/index.html` 离线可运行（图标用内联 SVG 或 Unicode）
- 全部文案与数据逐字取自 `prd/模块PRD/00-叙事主线与全局数据字典.md`（下称"数据字典"），不得自行编造或"顺手修正"预埋差错
- 视觉规范逐项遵守 `prd/模块PRD/G-全局组件.md` §六（色板/字号/间距/动效时长）
- 每个视图模块一个 JS 文件、每类数据一个数据文件；文件按本计划 File Structure 命名
- 兼容 Chrome/Edge，1920×1080 优化
- 本项目非 git 仓库且用户未要求初始化，各任务不含 commit 步骤；每任务以浏览器验收代替
