# M3 智能写作台双模式布局 — Design Spec

| 项目 | 内容 |
|------|------|
| 日期 | 2026-07-19 |
| 状态 | 已确认，进入实施 |
| 范围 | `demo/assets/app.js`、`demo/assets/styles.css`（M3 `renderWriting`） |

## 决策摘要

| 议题 | 结论 |
|------|------|
| 总体 | 主线按写作台三栏理顺；结构化模板保留为次要能力 |
| 入口 | 顶栏互斥 Tab：`深度报道` / `结构化模板` |
| 段落协同 | 沿用现有五键矩阵（扩写·降重·润色·短视频·翻译）；无 `rewrites` 映射的段落无菜单 |
| 标题 | 右栏精简入口 → 弹层三卡单选采用 |
| 模板与主稿 | 完全隔离：模板预览不写稿纸、不参与提交审校 |

## 信息架构

```
[全局导航]
[退回横幅 · 仅 returnNote]
[模式条]  ○ 深度报道（主线）  ○ 结构化模板

── writingMode === "depth" ──
左：选题卡摘要 + 统一素材池（公开 / 原创分组 + 信源状态）
中：空态生成按钮 → 稿纸（标题占位；段落选中）
右：选段操作 / 对比卡 /「打开标题工坊」/「提交审校」

── writingMode === "template" ──
单栏：财经/体育/天气模板卡 → 生成等待 → 结果预览
无三栏稿纸；无提交审校
```

## 状态

- 新增 `writingMode: "depth" | "template"`，默认 `"depth"`
- `writingTemplate` 仅用于模板态，取值 `finance | sports | weather`（不再用 `depth` 表示主线）
- 从采集进入、退回再进、步骤条进入：一律 `writingMode = "depth"`
- 模板态切换不中断深度态已有初稿 / 改写 / 标题状态

## 深度态交互

1. **生成初稿**：按钮文案含公开/原创素材计数；生成中锁交互；双击空格可跳过（沿用全局）
2. **段落协同**：选中 → 有映射则五键；点击 → AI 等待 → 对比卡（原文 + 建议）→ 采用写入 `buildRewrite` 结果 / 放弃清空；切段视为放弃未决对比
3. **标题工坊**：右栏显示当前标题摘要 + 按钮；弹层三卡互斥；采用后关闭并刷新稿纸标题
4. **提交审校**：需 `articleGenerated && selectedTitle !== null && !articleTyping`；确认后进 M4
5. **退回**：顶栏红色横幅；提交文案「修改后重新提交审校」

## 模板态交互

- 三卡选择 →「自动生成基础稿件」→ 等待 → 预览 sample
- 文案明示：演示用结构化生成，不进入主线送审
- 切回深度报道时保留 `templatePreview`，但不导入稿纸

## 不做

- 自由 contenteditable
- 模板结果导入主稿
- 左栏折叠（本次不排期）
- 溯源双向联动完善（保持现有弹窗级溯源即可）

## 验收

- [x] 默认进入深度三栏；模式条可切到模板单栏
- [x] 模板生成不影响中栏稿纸与提交按钮可用性逻辑
- [x] 采用改写写入当前操作对应文本，而非固定 `D.rewrites`
- [x] 标题经弹层采用后稿纸标题更新；未选标题不可提交
- [x] 退回横幅与重新提交仍可用
