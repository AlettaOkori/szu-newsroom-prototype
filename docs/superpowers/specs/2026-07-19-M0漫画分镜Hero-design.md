# M0 工作台：漫画线稿分镜 Hero 设计

| 项目 | 内容 |
|------|------|
| 状态 | 待用户确认文档 |
| 确认日期 | 2026-07-19（对话内 §1–§4 已确认） |
| 适用范围 | `demo/` M0 编辑部工作台（`m0-dashboard.html` / `renderDashboard`） |
| 参考视觉 | 用户提供的错落漫画分镜排版截图（白底、线稿、局部淡彩） |
| 不在范围 | `interactive-newsroom-hero` 三维微缩工位；不替换 A1–A6 模块内部页 |

## 1. 目标

把 M0「生产流水线」的开场认知，从六列看板为主，改为：

1. **Hero 分镜带**：六个漫画线稿分镜框，对应 A1–A6，错落排版；
2. **精简看板下移**：保留状态流转与主线稿件卡，高度与灰卡密度下调；
3. **悬停可读**：轻抬 + 淡彩铺开 + 旁白露出，点击进入对应模块。

听众先建立「六站流水线」的视觉心智，再在下方看板看到「稿件此刻在哪」。

## 2. 已确认决策

| 决策点 | 选择 |
|--------|------|
| 信息架构 | **B**：分镜作 Hero，看板下移保留 |
| 插画语义 | **A**：按 A1–A6 新闻生产语义原创，非参考图内容照搬 |
| 悬停 | **A+C**：轻抬 + 淡彩铺开，并露出阶段旁白 |
| 实现路径 | **1**：内联/文件 SVG 分镜 + CSS；精细度必须对标参考截图 |
| 精细度兜底 | 单框达不到截图质感时，该框改为同风格外链 SVG，交互壳不变 |

## 3. 页面结构

自上而下：

1. **顶栏**：现有步骤条、品牌、角色徽章不变。
2. **页头**：`M0 / 编辑部工作台` + 短描述 +「开始演示 / 继续当前稿件」主按钮；概览四数字保留为紧凑一行（可不改语义：线索 / 在产 / 已发布 / 提效）。
3. **Hero：生产流水线分镜带**（新主视觉）
   - 白底、大留白；
   - 六框横向错落（高-低-高-低-高-低），间距与框比例贴近参考图；
   - 每框：漫画线稿 + 框下旁白区（默认短横线占位；悬停展开文案）。
4. **精简看板**：标题仍为「生产流水线」；六列更矮；主线卡 + 少量灰卡。

### 3.1 交互映射

| 控件 | 行为 |
|------|------|
| 分镜框点击 / Enter | 进入对应 A1–A6（与现有 `target` 路由一致） |
| 「开始演示 / 继续」 | 仍跳到当前 `storyStatus` 映射的模块 |
| 主线稿件卡 | 逻辑不变：点击进入当前环节 |
| 灰卡 | 不可交互 |

分镜高亮阶段与看板主线列共用同一 `idx`（由现有 `storyStatus` 映射表推导），禁止两套状态。

## 4. 六框语义与插画标准

| 序号 | 模块 | 画面意图 | 淡彩强调 |
|------|------|----------|----------|
| 1 | A1 智能选题 | 编辑对着热力屏 / 选题卡，雷达波或信号点 | 黄 |
| 2 | A2 智能采集 | 记者戴耳机、麦克风或录音笔、素材碎片 | 青 |
| 3 | A3 智能写作 | 人探出框打字或举稿，纸页飞出 | 黄（纸页） |
| 4 | A4 智能审校 | 伏案改稿，红笔批注可见 | 报头红浅底 |
| 5 | A5 全渠道分发 | 多屏 / 手机帧；框外可有小无人机轨迹（呼应演示主线） | 青 + 粉 |
| 6 | A6 效果洞察 | 戴耳机看仪表盘或网络节点 | 青 |

### 4.1 精细度门槛（验收）

必须达到用户参考截图的观感级别：

- 线宽有粗细变化，边角略抖，手绘感而非几何图标 / 火柴人；
- 人物具备发型、体态、道具层次；
- 每框仅 1–2 个物件上色，其余纯线稿；
- 至少一框有「溢出框外」元素（默认 A5 无人机轨迹）；
- 近看路径清晰，投屏不糊成色块。

### 4.2 旁白文案（悬停露出）

默认框下 2 条短横线；悬停 / 聚焦时替换为：

| 模块 | 标题行 | 职责一句（约 ≤18 字） |
|------|--------|------------------------|
| A1 | A1 智能选题 | 聚合热点，决定报道角度 |
| A2 | A2 智能采集 | 公开资料与原创采录并行 |
| A3 | A3 智能写作 | 多信源成稿，人机共写 |
| A4 | A4 智能审校 | 证据核对，总编签发 |
| A5 | A5 全渠道分发 | 一稿适配多平台发布 |
| A6 | A6 效果洞察 | 读传播信号，回流选题 |

## 5. 悬停与动效规格

### 5.1 默认

- 六框静止错落；
- 当前稿件所在阶段：框角或左侧细红竖标（不抢戏）；
- 旁白区为短横线占位。

### 5.2 悬停 / `:focus-visible`（180–220ms）

1. 该框 `translateY(-6px) scale(1.04)`；
2. 其余框透明度降至约 `0.55`；
3. 淡彩从物件扩散为整框浅底（阶段强调色，约 12–18% 透明度）；
4. 占位横线淡出 → 标题 + 职责一句；
5. 溢出元素（如 A5 轨迹）轻微位移或描边加深。

### 5.3 点击

- 短促按下感（约 `scale(0.98)`）后跳转；
- `prefers-reduced-motion: reduce`：取消位移与缩放，仅保留浅底与旁白显隐。

### 5.4 触屏

- 第一次点按：选中并露出旁白（等同悬停态）；
- 第二次点按同一框：进入模块。

## 6. 看板精简

- 紧挨 Hero 下方，标题「生产流水线」；
- 列高约现有看板的 55–65%；
- 每列灰卡最多 1–2 张（现有 `ghosts` 可截断，不必删数据源）；
- 主线卡五元素与 `storyStatus` → 列位映射沿用现有逻辑；
- 不在本设计中重做 FLIP 流转（若已有则保留；缺失不阻塞本次 Hero）。

## 7. 技术落点

| 文件 | 变更 |
|------|------|
| `demo/assets/app.js` | `renderDashboard`：插入分镜 Hero markup；看板灰卡截断；绑定点击 / 触屏二次确认 |
| `demo/assets/styles.css` | 分镜带错落布局、悬停、reduced-motion、看板压缩样式 |
| `demo/assets/frames/`（新建，可选） | 达不到内联精细度时的外链 SVG（`a1.svg` … `a6.svg`） |

实现优先精细手绘 SVG（多 path、不规则描边）。颜色变量尽量复用现有设计 token（油墨黑、报头红、青、黄等），Hero 区背景用纯白 / 近白以贴近参考，不必强行铺满铅字纸纹。

全局顶栏、步骤条、教学浮层、重置流程不改行为契约。

## 8. 非目标

- 不把看板完全删除；
- 不引入订阅表单等参考图装饰 UI；
- 不改 A1–A6 内页视觉；
- 不依赖 Blender / 视频预渲染；
- 不做独立插画后台或 CMS。

## 9. 验收标准

1. 打开 M0，首屏主视觉为六框错落漫画分镜，而非六列等高看板。
2. 六框语义可辨认为选题→采集→写作→审校→分发→洞察。
3. 插画精细度目测达到参考截图级别（见 §4.1）；任一框不达标则换外链 SVG 直至达标。
4. 悬停：轻抬 + 浅底淡彩 + 旁白露出；其余框让位降透。
5. 点击分镜进入正确模块；主线卡与「开始演示」行为与改前一致。
6. 当前 `storyStatus` 对应分镜有细红标，且与看板主线列一致。
7. 看板仍可见且更矮；灰卡密度下降。
8. 键盘可聚焦分镜并 Enter 进入；`prefers-reduced-motion` 下降级正确。
9. 桌面宽度正常；窄屏下分镜可横向滚动或两行错落，不重叠不可点。
