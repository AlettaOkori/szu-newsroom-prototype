# 智媒编辑部视觉设计规范

| 项目 | 内容 |
|------|------|
| 状态 | 已确认 |
| 确认日期 | 2026-07-18 |
| 视觉原型 | `design/方案A-最终组合-A5F-A6E.html` |
| 适用范围 | M0-M6 演示原型 |

## 1. 设计命题

用界面材质讲述新闻的媒介旅程：

1. A1-A4：新闻在编辑部内部完成选题、采访、写作与审校，使用“铅字新闻”编辑设计；
2. A5：签发稿进入多平台传播，界面切换为“动态媒体拼贴”；
3. A6：发布内容转化为传播数据，媒体帧收缩为“数据网络场”中的节点；
4. A6 生成的新选题返回 A1，数据节点重新落版为纸面头条，形成视觉与业务双闭环。

## 2. 全局继承关系

| 继承项 | 规则 |
|--------|------|
| 新闻身份 | A1-A4 使用暖白纸底、油墨黑、衬线大标题、报头红与细栏线 |
| 结构骨架 | 全部模块保留 A1-A6 编号、全局步骤条、角色徽章、统一页脚 |
| 责任语义 | 报头红只用于立项、风险、签发等人工责任动作 |
| 数字语义 | 青色 `#00A9BD` 表示内容信号；洋红 `#FF3AA7` 表示受众反馈；黄色 `#FFED00` 表示发布动作与新选题 |
| 字体关系 | 新闻标题与洞察结论使用衬线；状态、平台、数据标识使用等宽字体；正文使用系统无衬线 |

## 3. A1-A4：铅字新闻

- 背景：暖白 `#F7F5F0`，内容白 `#FDFCF9`；
- 文字：油墨黑 `#1A1817`，次级灰褐 `#5C5852`；
- 关键色：报头红 `#C8102E`，AI 批注黄 `#FFE96B`；
- 组件：直角或 0-4px 小圆角、1px 栏线、3px 双线大分隔；
- 标题：Georgia / 中文宋体回退；
- AI 表达：荧光批注、编辑注记、红笔校样，不使用通用聊天气泡。

## 4. A4 → A5：签发转场

签发印章盖落后执行 1.2 秒转场：

1. 红色签发章定格 300ms；
2. 稿件版面沿横向切分为三个矩形媒体帧；
3. 背景切换为发布黄 `#FFED00`；
4. 三个媒体帧分别进入公众号、微博、短视频位置；
5. 动态跑马带开始运动，进入 A5 可操作状态。

用户跳过动画时，直接显示 A5 终态，不重复触发状态写入。

## 5. A5：动态媒体拼贴

### 5.1 设计语言

- 主背景：发布黄 `#FFED00`；
- 结构：3px 油墨黑描边、硬阴影、倾斜媒体帧、动态跑马带；
- 强调：受众反馈洋红 `#FF3AA7`、内容信号青 `#00D7FF`；
- 标题：超大无衬线粗体英文 `ONE STORY / EVERY SCREEN`；
- 视觉重心：内容版本是“媒体帧”，不是后台卡片或手机壳阵列。

### 5.2 信息层级

1. 超大主题标题；
2. 签发人与 3/3 渠道就绪状态；
3. 三个媒体帧：公众号、微博、短视频；
4. 跑马带：平台名、字数、时长、生成状态；
5. 一键适配 / 全渠道发布主按钮。

### 5.3 动效

- 三帧按 0 / 0.5 / 1 秒错峰进入；
- 帧进入采用旋转 + 位移 + 硬阴影落位；
- 跑马带持续水平运动；
- 生成完成后每帧显示 `READY`；
- 发布时媒体帧缩小为青/洋红/黄色数据包，进入 A6 转场。

## 6. A5 → A6：媒体帧数据化转场

全渠道发布后执行 1.5 秒转场：

1. 三帧显示已发布状态；
2. 每帧收缩为 9px 数据包；
3. 数据包沿连接线移动；
4. A5 黄底淡出为 A6 冷白点阵底；
5. 数据包分别落入公众号、微博、短视频传播节点；
6. A6 数据指标和连接线开始动画。

## 7. A6：数据网络场

### 7.1 设计语言

- 背景：冷白 `#F7FAF9` + 26px 点阵；
- 结构：1px 冷灰描边、半透明白色节点、传播路径曲线；
- 信号色：内容青 `#00A9BD`、反馈洋红 `#FF3AA7`、新选题黄 `#FFED00`；
- 标题：大号衬线结论；
- 元数据：等宽字体显示节点、数据包、时延与系统状态。

### 7.2 信息层级

1. 结论标题：传播不是终点，而是信号的开始；
2. 左侧网络图：签发稿源节点 → 三平台传播节点；
3. 路径上的数据包与平台指标；
4. 右侧 AI 信号解读：数据、受众关切迁移、下一条选题；
5. `ROUTE NEXT STORY` 闭环按钮。

### 7.3 动效

- 媒体数据包沿三条曲线路径移动并落入节点；
- 节点落位后依次显示指标；
- AI 解读最后生成；
- 闭环时黄色新选题数据包沿反向路径飞出，跳转 A1 后落为 H7 头条卡。

## 8. 可访问性与投屏约束

- 以 1920×1080 为主设计尺寸，1440px 宽可完整展示；
- 不依赖低对比度玻璃效果表达关键信息；
- 正文与背景对比度不低于 4.5:1；
- 动态跑马带不承载唯一信息，静态媒体帧内保留全部状态；
- 全局“跳过动画”必须覆盖签发切帧、媒体帧数据化与闭环回纸三段转场。

## 9. 自检结论

- 无未定义颜色、状态或转场；
- A5 与 A6 结构明显不同，但共享信号色、等宽元数据和媒体帧数据化关系；
- A1-A4 与 A5-A6 的差异服务于媒介旅程，不是无依据换肤；
- 视觉转场与现有稿件状态机一一对应，不新增业务状态。
