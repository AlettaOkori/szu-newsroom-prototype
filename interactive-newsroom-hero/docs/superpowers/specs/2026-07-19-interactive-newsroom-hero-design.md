# 互动式智能新闻编辑部首页设计

## 目标

为“智媒编辑部”制作一个原创白色微缩模型风首页。场景包含六个工位和六名角色，分别对应 A1–A6 新闻生产模块。页面通过预渲染动画营造三维质感，并支持桌面悬停高亮、角色响应、信息展示及模块跳转。

设计借鉴“预渲染场景承载网页交互”的技术机制，但不复制 Marvis 的角色轮廓、空间布局、镜头、配色、模型或动画素材。

## 第一阶段范围

先制作一个 5 秒概念样片，用于验证视觉质量与技术链路：

- 一个白色微缩工位
- 一名统一基础造型的角色，穿红色服装
- 显示器、键盘、座椅和必要桌面道具
- 柔和棚拍灯光、接触阴影和白色背景
- 镜头缓慢推进后进入可循环待机段
- 角色呼吸、敲键盘和悬停抬头动作
- 输出 MP4 主动画、静态封面和透明交互层

样片通过确认后再扩展到完整六工位场景。

## 完整场景

六个工位采用不规则环形布局，留出清晰的视觉中心和信息卡空间。所有角色使用同一原创微缩人偶基础造型，不用外轮廓区分身份；通过服装颜色、动作和桌面道具表达不同职责。

| 模块 | 角色 | 服装色 | 代表动作与道具 |
| --- | --- | --- | --- |
| A1 智能选题 | 策划编辑 | 红色 | 查看热点屏、移动选题卡 |
| A2 智能采集 | 记者 | 橙色 | 戴耳机、整理采访素材 |
| A3 智能写作 | 文字编辑 | 绿色 | 敲键盘、查看稿件 |
| A4 智能审校 | 审校编辑 | 紫红色 | 标记文本、确认问题 |
| A5 全渠道分发 | 运营编辑 | 黄色 | 切换多块平台屏幕 |
| A6 效果洞察 | 数据分析师 | 青色 | 查看图表和传播信号 |

## 动画状态

### 入场

白色空间淡入，镜头从稍远位置平滑推进。工位按空间层次依次显现，最终停在固定俯视斜角。

### 待机

角色保持轻微呼吸、敲键盘或查看屏幕等循环动作。屏幕内容缓慢变化，灯光稳定，不使用会分散注意力的大幅运动。

### 悬停

命中工位后：

1. 工位、角色服装和地面光圈在 100ms 内开始提亮。
2. 对应角色抬头或转身，屏幕切换到模块主题画面。
3. 其他工位降低亮度与对比度，但保持可辨识。
4. 工位旁出现信息卡，显示模块编号、名称、角色身份、职责简介和“点击进入”提示。

### 点击

点击后执行短促的镜头推进和角色确认动作，再进入对应 A1–A6 页面。过渡动画不超过 500ms，且允许用户通过减少动态效果偏好关闭。

## Web 技术结构

主场景由以下独立图层组成：

1. **主动画层**：原创预渲染 MP4，包含镜头入场和场景待机循环。
2. **热区层**：覆盖六个与桌面透视轮廓匹配的 SVG 多边形，负责鼠标、触控和键盘命中。
3. **高亮层**：每个工位单独输出透明 WebM 或 PNG 序列，用于局部灯光和角色响应。
4. **信息层**：HTML/CSS 信息卡，保证文字清晰、可访问且容易修改。
5. **配置层**：JavaScript 数据定义模块编号、角色、颜色、文案、热区和目标地址。

MP4 不承担命中检测。工位交互由 SVG 热区驱动，视频仅负责视觉表现。

## 素材生产

优先使用 Blender 与 Python 自动化生成原创低多边形场景：

- 使用基础几何体构建桌椅、显示器和角色
- 使用统一材质体系，仅服装和屏幕使用模块强调色
- 使用固定相机和统一灯光保证各分层完全对齐
- 分别渲染主动画、遮罩、高亮和角色响应序列
- 使用 FFmpeg 将帧序列编码为 MP4/WebM

若本机缺少 Blender 或 FFmpeg，先完成网页交互原型和静态分层示意，并明确列出缺失的渲染依赖；不以低质量录屏冒充最终预渲染素材。

## 响应式与降级

- 桌面端：鼠标悬停显示信息，点击进入模块。
- 触屏端：第一次点击选中并显示信息，第二次点击进入模块。
- 键盘：每个工位均可通过 Tab 聚焦，Enter 进入模块，Escape 取消选中。
- 低性能设备：使用静态封面和 CSS 高亮，不加载透明角色动画。
- `prefers-reduced-motion`：跳过镜头推进和角色响应，仅保留即时状态切换。

## 失败处理

- 主视频加载失败时显示静态封面。
- 单个透明高亮层加载失败时退化为 SVG 光圈和信息卡，不阻断导航。
- 自动播放被浏览器阻止时显示静态首帧，并在首次用户交互后启动。
- 目标页面不存在时不执行跳转，并显示明确提示。

## 验收标准

- 5 秒样片具有原创微缩模型风格，角色、桌椅和阴影关系清晰。
- 待机循环首尾无明显跳帧或亮度变化。
- 六个桌面热区与画面轮廓准确匹配，不出现明显串区。
- 悬停反馈在 100ms 内开始，信息卡不遮挡当前角色。
- 角色在所有状态中都存在，且服装颜色与模块映射一致。
- 点击每个工位可进入正确的 A1–A6 页面。
- 键盘与触屏可完成同等操作。
- 普通笔记本电脑可流畅播放；降级模式仍可完成导航。

## 非目标

- 不复制第三方角色、模型、视频、镜头或页面源码。
- 第一阶段不制作六个完整工位。
- 不在样片阶段引入后台管理、在线文案编辑或复杂数据接口。
- 不承诺仅靠程序化基础模型达到商业广告级三维角色精度。
