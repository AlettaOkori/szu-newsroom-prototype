## 一、叙事主线总览

一条新闻贯穿六模块的完整旅程：

| 环节 | 剧情节点 |
|------|---------|
| M1 选题 | 热点雷达捕捉"低空经济"热度飙升 → AI 生成 3 个报道角度 → 编辑选定民生视角立项 |
| M2 采集 | 公开资料采集与原创采访并行：AI 汇集政策/企业/历史资料；采访实时转写与萃取；两轨进入统一素材池并完成信源对齐 |
| M3 写作 | AI 基于选题卡与素材生成初稿（预埋"12 万单"差错与"全国第一"表述）→ 记者协同修改 → 选定标题 |
| M4 审校 | AI 报告 4 条问题（高1/中1/低2）→ 主编逐条裁决 → 签发 |
| M5 分发 | 一键生成公众号/微博/抖音三版本（可选英文版）→ 仿真预览 → 全渠道发布 |
| M6 洞察 | 传播数据看板 → AI 复盘报告 → 追踪选题建议"低空物流安全监管" → 闭环回 M1 |

**虚构声明**：涉及企业（翎航科技）与人物（陈明宇、李婷、张倩、王一舟等）均为虚构，数据为演示编造，界面需在页脚标注"演示数据，均为虚构"。

**第 8 段（公共讨论）**
